# Village archive HUD

The archive uses a compact header, a persistent sidebar for island selection and sections, and a separately scrolling content area. Parchment, sage, river teal, and Nunito preserve the surrounding game's HUD theme. On phones, islands and section navigation move above the content. Connection statuses stay in a quiet footer; they reflect the live API response.

The council retains its evidence, approval, rejection, and publication-retry actions. Filters show actual observation counts. Its empty state links directly to experiment setup. Run history retains all nine outcome columns and expandable seed, model, comparison-group, and condition details. Experiment settings use the same saved preferences and apply to the next Start. Background interaction and scrolling are blocked while the archive is open; Escape restores focus to its launcher, and section tabs support arrow keys, Home, and End.
